---
title: "Get order details"
description: "Returns an on-chain DEX or bridge order created in the last 48 hours."
openapi: "GET /orders/{houdiniId}"
---

Poll this with the `houdiniId` from [Create exchange](/api-reference/on-chain-dex-or-bridge/create-exchange), after calling [Confirm DEX transaction](/api-reference/on-chain-dex-or-bridge/confirm-dex-transaction).

Past the 48-hour window the order drops out of the API and returns 404, the same as an id that never existed, so store whatever you need to keep before then.
